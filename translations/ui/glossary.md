## 技能说明句式统一（2026-10-14 第二轮）

以下用于效果说明，不机械替换角色名称、招式名称或剧情台词。完整角色名优先按 `TskNames.json` 匹配；例如完整名中的“（幼少）”不按通用词“幼年”拆换。“カリスマ→领袖魅力”限定战斗状态，不覆盖人物称号中的一般修饰语。

| 日文/效果 | 统一表达 | 边界 |
|---|---|---|
| 敵全体／敵単体 | 敌方全体／敌方单体 | 保留属性、位置、数量限定 |
| 味方全体 | 我方全体 | 敌人介绍中的其友方按叙述视角保留 |
| 指定相邻范围 | 目标及其左右各N列范围内的所有敌人 | 不缩成敌方全体 |
| ノーツ前方移動 | 行动位置向前移动 | 不擅自新增“格”单位 |
| ノーツ強制後方移動 | 行动位置强制向后移动 | 普通击退仍用“击退” |
| チャージ時の戻り量 | 蓄力时的行动位置后退量 | 不与强制移动混淆 |
| 普通数值アップ | ATK/重量/伤害提升N％ | 保留EX上升这一属性名 |
| クリティカル加算 | 暴击率加算N％／暴击伤害倍率加算N％ | 不改成普通乘算提升；保留额外 |
| 行動CT短縮／遅延 | 行动CT缩短／行动CT延迟 | 保留比例及条件 |
| HP・EX回復 | HP回复／EX槽回复 | 状态恢复、招式名不机械替换 |
| 状態異常耐性アップ | 异常状态耐性提升N级 | 具体状态名称与全异常限定按原文 |
| EX吸收后返还 | 并以吸收量的N％回复我方EX槽 | 保留吸收源、公式和计数对象 |
| 確率付与 | 以N％的概率赋予… | 保留强制眩晕与普通状态差异 |
| 耐久护盾 | 为我方展开耐久值相当于技能使用者HP的N％的护盾 | 不与攻击次数护盾合并 |
| 次数护盾 | 为我方展开使N次攻击无效的护盾 | 保留次数 |
| 次回以降のEX发动期间 | 从下回合起，持续至发动N次EX技能为止 | 根据实际源文判断起点 |
| 各対象の行動終了まで | 持续至各目标第N次行动结束 | 不简化成“持续N回合” |
| チームスキル | 团队技能 | 道具和功能说明统一 |

修饰“提升值”“提升上限”时保留完整对象，不能缩写成该属性自身提升。百分号宽度与原有着色、公式占位符保持，避免纯排版变更干扰数值核验。
