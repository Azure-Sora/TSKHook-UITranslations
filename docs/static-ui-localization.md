# 静态 UI 汉化（2026-10-14）

`translations/ui/static-ui.jsonl` 保存游戏原生 UI 中未被网络 JSON 捕获覆盖的文字。它与既有网络译文共同生成一个 `ui_translations.jsonl`，由正式插件在文本渲染层使用。玩家不需要安装 UI Inspector；该工具只用于维护者安全探索和实机核对。

## 维护方式

每行字段为 `schemaVersion:1`、`source`、原文 SHA-256 `sourceHash`、`translation`、显式 `status` 和用于追溯的 `origins`。只发布 translated 状态；needs_review 和 excluded 不发布。机器整理的条目保持 translated，不据此宣称每个隐藏节点都经过显示验收。

固定标签保持精确匹配。`template:true` 表示数字、日期或时间拼接模板，例如：

```json
{"schemaVersion":1,"source":"スタミナが {0} 回復します。必要数: {1} 個","sourceHash":"以模板本身计算的SHA256","translation":"恢复 {0} 点体力。需要: {1} 个","status":"translated","template":true,"origins":["ui:游戏中核对的位置"]}
```

模板使用 {0}..{3}，不能填写正则表达式或任意文本通配符。参数限定为有界数字、日期、时间字符；重复参数必须相等，必须整段匹配，冲突结果不替换。富文本标签、占位符和换行由现有发布校验继续检查。模板最多 64 条，不为每个日期、当前数量或账号昵称添加记录。

静态 UI 文件由 `StaticUiCatalog` 校验并参与工作目录变动检测，CompileUiRuntime、BuildPackage 和工作台编译均自动合并它。它不进入工作台导入/模型队列，也不会重写原有 source/by_category 文件。每条运行时记录标为 `renderedOnly:true`，模板附带 `sourceTemplate`；包清单最低插件版本提升为 1.4.6。显示层支持 setter、OnEnable 和 TMP 渲染前更新，覆盖初始序列化文本及绕过 setter 的 SetText 路径。

## 本轮边界与证据

当前共 488 条，包括 471 个精确文字、17 个模板。首批 325 条覆盖菜单、设置各隐藏面板、仓库、音乐界面、奖杯、图鉴及排序筛选、任务、礼物箱、体力恢复说明、关卡/出击准备、角色详情、装备、编队、剧情目录、商店/兑换所。后续加入个人资料、只读系统目录、四个页签的悬停台词，以及巡逻、联合演习、高塔、种族交流会、星骑士故事筛选、抽卡确认/详情/概率/集章说明。系统目录遍历 170 个 TextType，返回 169 个非空文本，零错误。

网络捕获源哈希和既有译文值用于排除业务文本，角色/账号名称、测试占位字、已译中文与临时数值另行剔除。探索中新捕获的招募长篇说明、首领名等仍走既有网络流程，本轮不重复翻译。抽卡确认模板中的「精选扭蛋」是已知固定名称，仅数量和消耗数字作为参数；其他招募名称不会被任意文本通配符匹配。

没有确认购买、抽卡、使用道具、领取、出售、出击或提交设置。用户允许打开低风险确认前页面后，进入宝石恢复和单抽/十连确认，但均关闭而未执行。个人资料仅查看标签；账号登录、关联、删除等管理页面没有进入。故事排序升降序检查后立即切回，筛选弹窗关闭而未应用。部分模块标题、主导航、教程内容为 Image/Spine 中的文字，本轮文字替换不覆盖这些像素。仍未进入的高风险、活动特殊、战斗进行中及账号页面不能宣称全部覆盖。

**先前已知自动副作用**：首次进入抽卡主页面，游戏自行弹出过期 pt／票券 105 → 10,500 特尔斯的转换通知；没有发出抽卡或兑换指令。发现后立即向用户说明，关闭通知并退出，没有尝试回退账号数据。后来在用户明确允许打开抽卡确认页的范围内继续检查；本轮只有打开和取消，主页读回宝石仍为 609400、特尔斯为 244892528。
